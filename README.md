Reusable Nuxt 4 presentation foundation for the `nuxt4-layers` platform.

The layer owns semantic design tokens, accessibility-safe presentation defaults, validated theme application, and explicitly public UI primitives. It does **not** own authentication, authorization, account settings, application navigation data, or preference persistence.

## Public surface

- `@nuxt4-layers/ui` — Nuxt layer
- `@nuxt4-layers/ui/theme` — theme types and validation/application helpers
- `UiSurface` — representative accessible presentation primitive

See `docs/contracts.md` for the bounded contract.
